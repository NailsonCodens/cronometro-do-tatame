## English (Default)

### Short description

```
Round timer for Brazilian Jiu-Jitsu training. Big, readable, and fully offline.
```

### Long description

```
A round timer built for the mat, not for your pocket.

Set the round, set the rest, press OK. It runs one round after another until
you stop it — so nobody has to keep looking at a phone.

The countdown fills the screen, readable from anywhere in the room. The colour
tells you how much is left without reading the number at all: it starts green,
warms through yellow and orange, and turns red in the final ten seconds.

WHAT YOU GET

• Round, rest and preparation times you can set freely
• Shortcuts for the usual pairings: 5+1, 6+1, 8+2, 10+2, 3+0:45
• A horn at the end of the round, a rising chime when the next one starts —
  two sounds shaped to be told apart across a noisy room
• One beep per second in the last ten seconds, the final one long and low
• Unlimited rounds, or a fixed number
• Adjustable volume, and a test button to set it before class

BUILT TO BE LEFT ALONE

No account. No ads. No tracking. Nothing is collected.

It makes no network requests at all — the fonts are embedded and the sounds are
generated as they play, so the app works exactly the same with the TV offline.

Everything is driven by the remote: OK starts and pauses, the arrows move
between buttons, and the selected button lights up so you can see it from the
other side of the mat.
```

## Português (Brasil)

### Descrição curta

```
Cronômetro de rolas para treino de jiu-jitsu. Grande, legível e funciona offline.
```

### Descrição longa

```
Um cronômetro feito para o tatame, não para o bolso.

Ajuste o tempo de rola, ajuste o descanso, aperte OK. Ele emenda um rola no
outro até você mandar parar — ninguém precisa ficar olhando o celular.

O número ocupa a tela inteira e se lê de qualquer canto da sala. E a cor conta
quanto falta sem você precisar ler: começa verde, esquenta passando por amarelo
e laranja, e fica vermelha nos dez segundos finais.

O QUE TEM

• Tempo de rola, descanso e preparação, todos configuráveis
• Atalhos para as combinações mais usadas: 5+1, 6+1, 8+2, 10+2, 3+0:45
• Buzina no fim da rola e um sino subindo quando a próxima começa — dois sons
  desenhados para não se confundirem no barulho da academia
• Um bipe por segundo nos dez últimos, com o final mais longo e grave
• Rolas sem limite, ou um número fixo
• Volume ajustável, com botão de teste para calibrar antes da aula

FEITO PARA SER ESQUECIDO NUM CANTO

Sem conta. Sem anúncio. Sem rastreamento. Nada é coletado.

Não faz nenhuma requisição de rede: as fontes vêm embutidas e os sons são
gerados na hora de tocar, então funciona igual com a TV sem internet.

Tudo pelo controle: OK inicia e pausa, as setas andam entre os botões, e o
botão selecionado acende para você enxergar do outro lado do tatame.
```
